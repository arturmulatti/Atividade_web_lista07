O HTML é conectado a um arquivo CSS externo por meio da tag link o atributo rel="stylesheet" diz ao navegador que o arquivo é uma folha de estilizações e o href="style.css" indica o caminho do arquivo a ser carregado.

A separação do HTML e do CSS facilita a manutenção e a orgazinação como por exemplo usar o mesmo arquivo CSS em várias páginas diferentes, melhorando o desempenho
